# Changelog — ESPHome Toshiba Suzumi
Date: 25 October 2026

### Fixed
- Removed the unused `packaging` import so the component loads without this Python package.
- Corrected boolean handling: `horizontal_swing`, `disable_heat_mode`, and `disable_wifi_led` now respect `false`.
- Fixed string comparisons for custom fan speeds.
- Added recognition of the 114-byte model information response. Model names are logged at debug level instead of triggering an unknown-message warning.

### Configuration
- Updated the external component source to `r1ck3rd/esphome_toshiba_suzumi`.
- Added `path: .` to match the current repository structure.
- Updated example configurations to the current OTA and ESP8266 syntax.
- Recommended adding `flash_chip: generic` to reduce IRAM usage.

### Verified
- Successfully compiled the component for ESP8266 with ESPHome 2026.10.0, with and without time synchronization.
- Validated both updated examples and generated their C++ source.
- Confirmed that the `airco-overloop` ESP32 runs ESPHome 2026.10.0 and is accessible through the API.
- Communication with and control of the air conditioner still require hardware verification.
